# Store Inventory Management

A console-based store inventory management program written in C++, developed as my first ever programming project.

Created for an Informatics assignment, this project was my first attempt at building a complete program from scratch — implementing logic, managing data, and working with persistent local storage.

## About

The program manages store-related information through a simple locally stored, file-based data system.

Instead of using a traditional database, it uses files to store and process data, essentially acting as a small homemade database. This allowed me to explore how information can be organized, manipulated, and preserved between program executions.

## What I Learned

This project represents the very beginning of my programming journey. While the code doesn't follow many of the practices I would use today, it gave me hands-on experience with:

- Writing a complete program from scratch
- Structuring logic to solve a real-world-inspired problem
- Manipulating and processing data
- Working with files for persistent storage
- Building a basic file-based data management system
- Understanding the importance of code organization and maintainability

## Tech Stack

- **C++**
- **File-based storage** — used as a simple local data persistence system

## Project Context

This was my first project ever written entirely by me, created for a school Informatics assignment.

It was built before I knew about concepts like **DRY (Don't Repeat Yourself)**, clean code, or more advanced software design principles. Looking back, there are plenty of things I would approach differently today — and that's exactly what makes this project meaningful to me.

It serves as a snapshot of where my programming journey started.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/alexgdin/evidenta_magazinului.git
```

Compile the source file using a C++ compiler:

```bash
g++ Evidenta_Magazinului.cpp -o evidenta_magazinului
```

Run the executable:

```bash
./evidenta_magazin
```
